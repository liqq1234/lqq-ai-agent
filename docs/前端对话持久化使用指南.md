# 前端对话持久化使用指南

## 📦 已实现的功能

### 1. API 接口封装
**文件**: `src/api/conversation.js`

提供了以下 API 方法：
- `createConversation()` - 创建新对话
- `getConversationList()` - 获取对话列表
- `getConversationDetail(id)` - 获取对话详情
- `saveMessage(data)` - 保存消息
- `deleteConversation(id)` - 删除对话
- `updateConversationTitle(id, title)` - 更新对话标题

### 2. Pinia Store 增强
**文件**: `src/stores/chat.js`

#### 新增状态
```javascript
conversations           // 对话列表
currentConversationId   // 当前对话ID
currentConversation     // 当前对话对象（计算属性）
```

#### 新增方法
```javascript
// 对话管理
loadConversations()         // 加载对话列表
createNewConversation()     // 创建新对话
switchConversation(id)      // 切换对话
deleteConversation(id)      // 删除对话

// 消息管理（已更新）
addMessage(message)         // 添加消息并自动保存
addUserMessage(content)     // 添加用户消息并保存
addAIMessage(content)       // 添加AI消息并保存
```

### 3. 组件更新

#### ChatLayout.vue
**改动**：
- 对话列表从 store 获取
- 创建/删除对话调用 store 方法
- 切换对话自动加载历史消息
- 页面加载时自动加载对话列表

#### ChatInterface.vue
**改动**：
- 发送消息前检查对话ID，没有则自动创建
- 用户消息自动保存到数据库
- AI 回复完成后自动保存到数据库
- 切换对话自动加载历史消息

## 🚀 使用流程

### 1. 页面加载
```
用户打开页面
  ↓
ChatLayout.onMounted()
  ↓
chatStore.loadConversations()
  ↓
显示对话列表
```

### 2. 创建新对话
```
点击"发起新对话"按钮
  ↓
createNewChat()
  ↓
chatStore.createNewConversation()
  ↓
调用 API: POST /api/conversation/create
  ↓
获取新对话ID
  ↓
清空消息列表
  ↓
更新对话列表
```

### 3. 发送消息
```
输入消息并发送
  ↓
检查是否有当前对话ID
  ↓
没有? 创建新对话
  ↓
addUserMessage(content)
  ↓
调用 API: POST /api/conversation/message/save
  {
    conversationId: xxx,
    role: "user",
    content: "消息内容"
  }
  ↓
发送到 AI 获取回复
  ↓
AI 回复完成
  ↓
调用 API: POST /api/conversation/message/save
  {
    conversationId: xxx,
    role: "assistant",
    content: "AI回复内容"
  }
  ↓
刷新对话列表（更新最后消息）
```

### 4. 切换对话
```
点击对话列表中的某个对话
  ↓
switchConversation(id)
  ↓
调用 API: GET /api/conversation/{id}
  ↓
加载该对话的所有历史消息
  ↓
显示在聊天界面
```

### 5. 删除对话
```
点击三个点菜单 → 删除
  ↓
deleteConversation(id)
  ↓
调用 API: DELETE /api/conversation/{id}
  ↓
刷新对话列表
  ↓
如果删除的是当前对话，清空消息
```

## 📝 代码示例

### 在组件中使用 Store

```vue
<script setup>
import { useChatStore } from '@/stores/chat'
import { onMounted } from 'vue'

const chatStore = useChatStore()

// 页面加载时获取对话列表
onMounted(async () => {
  await chatStore.loadConversations()

// 创建新对话
const handleNewChat = async () => {
  const conversationId = await chatStore.createNewConversation()
  console.log('新对话ID:', conversationId)
}

// 发送消息
const handleSend = async () => {
  // 如果没有当前对话，先创建
  if (!chatStore.currentConversationId) {
    await chatStore.createNewConversation()
  }
  
  // 发送消息（自动保存）
  await chatStore.addUserMessage(inputMessage.value)
}

// 切换对话
const handleSelectChat = async (chatId) => {
  await chatStore.switchConversation(chatId)
}

// 删除对话
const handleDelete = async (chatId) => {
  await chatStore.deleteConversation(chatId)
}
</script>
```

## 🔧 关键技术点

### 1. 自动保存机制
```javascript
const addMessage = async (message) => {
  // 先添加到本地
  messages.value.push(newMessage)
  
  // 然后保存到服务器
  if (currentConversationId.value) {
    await conversationApi.saveMessage({
      conversationId: currentConversationId.value,
      role: message.from === 'user' ? 'user' : 'assistant',
      content: message.content
    })
    
    // 刷新对话列表（更新最后消息和时间）
    await loadConversations()
  }
}
```

### 2. 消息格式转换
```javascript
// 后端格式 → 前端格式
messages.value = (res.data.messages || []).map(msg => ({
  id: msg.id,
  content: msg.content,
  from: msg.role === 'user' ? 'user' : 'ai',  // role → from
  type: 'text',
  timestamp: msg.timestamp,
  loading: false
}))

// 前端格式 → 后端格式
await conversationApi.saveMessage({
  conversationId: currentConversationId.value,
  role: message.from === 'user' ? 'user' : 'assistant',  // from → role
  content: message.content
})
```

### 3. 流式聊天保存
```javascript
// 在流式聊天完成后保存 AI 消息
if (data === '[DONE]') {
  chatStore.setLoading(false)
  
  // 保存完整的 AI 回复
  if (fullResponse && chatStore.currentConversationId) {
    await saveMessage({
      conversationId: chatStore.currentConversationId,
      role: 'assistant',
      content: fullResponse
    })
  }
}
```

## ⚠️ 注意事项

### 1. 用户身份验证
- 所有 API 请求需要携带用户认证信息
- 后端通过 `UserContext.getCurrentUserId()` 获取当前用户
- 确保用户登录后才能创建/访问对话

### 2. 错误处理
```javascript
try {
  await chatStore.createNewConversation()
} catch (error) {
  console.error('创建对话失败:', error)
  // 显示错误提示给用户
}
```

### 3. 性能优化
- 对话列表使用计算属性
- 消息列表使用虚拟滚动（大量消息时）
- API 调用添加防抖/节流

### 4. 数据一致性
- 创建对话后立即刷新列表
- 删除对话后检查当前选中
- 保存消息后更新对话列表

## 🐛 常见问题

### Q1: 为什么消息发送后对话列表没更新？
**A**: 检查是否调用了 `loadConversations()` 刷新列表

### Q2: 为什么切换对话后消息没加载？
**A**: 检查 `switchConversation()` 是否正确调用，查看控制台错误

### Q3: 为什么创建对话失败？
**A**: 检查用户是否已登录，查看后端日志确认错误原因

### Q4: 如何调试消息保存？
**A**: 打开浏览器控制台，查看：
```javascript
console.log('当前对话ID:', chatStore.currentConversationId)
console.log('消息列表:', chatStore.messages)
console.log('对话列表:', chatStore.conversations)
```
